# 管理界面视觉改造验收

日期：2026-11-14。范围：ModelBridge 0.4.1 管理前端；运行中的推理服务未重启。

## 参考与实现

参考 CLIProxyAPI 官方管理中心固定版本 `3d893ec88938c3ceef200a15be6af8cf972564b3` 的 `themes.scss`、`variables.scss`、`layout.scss`，选择性复用暖灰主题色，沿用紧凑导航、细边框和分层容器的设计方式。保留 React + Ant Design 和现有八页操作流程；没有引入 CLIProxyAPI 服务或管理中心整体代码。来源和 MIT 许可见 `THIRD_PARTY_NOTICES.md`。

- 统一浅色/深色主题、表格、卡片、输入框、按钮和弹窗。主题提供器包裹消息与确认弹窗，修复弹层未完整继承主题的问题；深色成功标签单独提高对比度。
- 标准图标、216px 可折叠侧栏、64px 顶栏；手机使用抽屉导航，内容区不再被侧栏挤占。
- 账号指南可收起，已有账号默认收起；统计区紧凑排列。编辑保留在表格，其他账号操作收进“更多”，确认和禁用条件保留。勾选后才展示批量工具栏。
- 概览将趋势和运行状态在桌面并排显示，手机纵向排列，补齐无请求时的图表空状态。
- 每页使用具体说明；历史请求错误明确标为“最近一次请求失败”，提供日志入口，没有清空历史错误或伪造成功状态。
- 直接声明已锁定、已安装的 `@ant-design/icons@6.3.4`，不增加其他 UI 框架。

## 2026-11-15 后续优化

- 配额页移除占据首屏的查询结果表，改为位于账号卡片之后的折叠明细；运行中、失败和中断的新查询默认展开。取消及失败重试仍保留。
- 单账号卡片使用整行宽度，额度窗口与订阅/积分分区展示，窄屏自动纵向排列。快照过期明确写为“快照已过期”和“历史剩余”，历史进度条使用中性色；没有推断恢复后的额度。
- 筛选工具栏合并，勾选后才显示批量刷新操作；查询时间和来源说明可展开。
- 设置按照请求连接、请求记录分组；本地导入使用标准按钮，文件只进入草稿；支持重复选择同一个文件。导入成功使用成功消息，不再显示错误重试提示。差异确认将配置键和布尔值改为中文标签。
