# 独立配额读取验收

## 原因与实现

- 原 `quota()` 仅返回不支持的占位结果，未请求额度接口。
- 使用 ModelBridge 自有 direct 会员授权请求官方 `/backend-api/wham/usage`，过期时401；通过本机服务刷新为有效令牌、目录读取200后，再次配额请求仍为401、`no_matching_rule`。确认不是单纯过期。
- 参考 CLIProxyAPI v8.0.69 的原生 Codex OAuth 参数与官方 Management Center `3d893ec88938c3ceef200a15be6af8cf972564b3` 的配额窗口分类；仅移植相关部分，保留 MIT 许可。
- 新增自己的 OAuth PKCE / nonce / state 回调、签名与账号校验、DPAPI 存储和独立刷新，直连官方额度接口。现有模型调用授权不替换。错误及页面不返回令牌、账号ID或上游原始错误正文。
- 支持套餐、主额度、代码审查、附加额度、恢复时间及额外积分。仅读取，不兑换重置积分、不修改超额消费设置。

## 范围

官方额度是时间窗口百分比，不转换成剩余token数。未返回的百分比显示未知；读取失败显示失败或重新授权，不展示估算余额。真实多账号、不同套餐的完整覆盖未执行。
