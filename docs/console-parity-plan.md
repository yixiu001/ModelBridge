# 独立网关与管理界面完善范围

2026-11-14，用户最新授权覆盖早期「复用底层服务」方案。仅 Codex OAuth；React + Ant Design；只选择性移植必要代码，不依赖 CLIProxyAPI 服务、程序或整体软件包，不接 API 供应商和插件。

## 实施

1. 复用 ModelBridge 原有官方会员授权、签名校验、DPAPI 和 SSE 解析。
2. 选择性移植 CLIProxyAPI v8.0.69 消息/工具历史重建与长调用编号处理；客户端完整历史为唯一输入，错误配对明确拒绝。
3. 自有账号管理、模型规则、配置、日志和验证任务。清除运行路径中的外部引擎绑定/转发模块及不再使用的配额代码。
4. 按官方管理中心的导航与操作逻辑完善现有八页：筛选、批量操作、详情、显式保存、冲突检查和导出。
5. 对照真实能力显示限制：不伪造配额、多账号路由或自动重试开关。
6. 重新验证8个可用模型的工具/文件/MCP与长会话，复测WorkBuddy原生连接及旧会话。
7. 独立只读审查、测试、文档与第三方许可、提交并推送。

## 验收原则

- 任何旧 CLIProxyAPI 通过记录都不充当新实现证据。
- 同一适配器和规则适用于目录中全部模型，推理档位依据官方能力声明。
- 不改变用户指定模型，不伪造工具结果；网络、超时和上游HTTP错误保留准确分类。
- 不读取其他应用凭据，不记录完整用户对话、令牌或授权回调。
- 只验证隔离测试文件和MCP夹具；本机现有CLIProxyAPI试用安装保留但不连接。
